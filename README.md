# FUNAT Campo (versão web)

App de campo da fiscalização da FUNAT – Tubarão/SC, versão para iPhone (instalar pelo Safari: Compartilhar › Adicionar à Tela de Início).

Este repositório contém só o site estático gerado por `src-app/build-web.py`. Não há dados, fotos, senhas nem chaves aqui: as vistorias ficam apenas em cada aparelho.
